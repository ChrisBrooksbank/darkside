# Enter The Prism

An interactive tribute site concept for Pink Floyd's *The Dark Side of the Moon*.

The experience treats the album as a listening observatory: a lunar-prism hero, an interactive track orbit, a studio-room section, thematic constellation, personnel system, and legacy timeline.

## Run Locally

```bash
npm install
npm run dev
```

Then open the local URL printed by Vite.

## Build

```bash
npm run build
```

## Notes

- The project includes a generated original hero image in `public/assets/`.
- No official audio or full lyrics are included.
- The visual language is inspired by prism optics and the album's themes, without recreating the original sleeve art exactly.
